# Safekeeping site

Live at https://safekeepingirl.com

- `site/` — everything Netlify publishes (the page, `support.js`, images in `assets/`)
- `supabase/` — database setup scripts (run by hand in the Supabase SQL editor; not published)
- `netlify.toml` — tells Netlify to publish the `site/` folder

Original design built in Claude Design; this copy is the October 2, 2026 export.
